# ClientSystem

Unity/C# 게임 클라이언트 개발 포트폴리오용 기술 데모 모음입니다.
하나의 완성된 게임을 만드는 대신, 클라이언트 사이드의 개별 기법(미니맵, 비헤이비어 트리, 퀘스트 시스템, 어드레서블 등)을
각각 독립된 씬으로 구현합니다. 각 기믹은 시작/종료 시점과 함께 아래 목차에 기록됩니다.

- 엔진: Unity 2022.3.62f2 (URP)
- 배포: 씬별 WebGL 빌드 (WebGL 미지원 기믹은 PC 빌드로 예외 처리, 해당 기믹 섹션에 명시)
